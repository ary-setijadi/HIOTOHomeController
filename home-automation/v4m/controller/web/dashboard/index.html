About

V4m — plaintext (no mTLS), local-only controller with a SQLite database. Devices are registered in the controller (SQLite registrations), rules come from rule_devices, and telemetry is bounded (≤10 MB memory + ≤50 MB on-disk rollover files). Click a device name to rename it inline; lists re-sort automatically after every edit.
